Guard Desktop

Family rules for their Windows PC.

Guard Desktop is the child app that connects a Windows computer to your Layers Guard parent account. It runs in the notification area and applies the rules you set from the dashboard or Android Controller.

What the Windows app does

Time & schedules

Track active foreground use, enforce daily and per-app limits, and apply bedtime and allowed app/site windows.

App & website controls

Block selected Windows applications and websites, pause internet access, and show a lock when the parent or schedule requires it.

Requests & diagnostics

Children can request time or access. Parents can inspect connection, startup and permission diagnostics and use PIN-gated stop or unpair actions.

Parent-led setup

  1. Contact us for the current Windows build. Place the app on the child’s PC.
  2. Complete the setup from a parent or administrator account and approve Windows permission when requested.
  3. Choose Get started in Guard Desktop. Open the parent dashboard or Android Controller and add the device using the displayed pairing code.
  4. When connected, finish setup and check the reported protection status. Configure time limits, bedtime, app rules and website rules.

Startup is registered during pairing. Different Windows accounts can have different protection capabilities. A standard child session may run with reduced protection when administrator-only website or firewall controls are unavailable.

A paired or online device is not necessarily fully protected. Review diagnostics and the protection status. The app does not guarantee that every Windows session has full controls, or that a child with administrator access cannot change system settings.
