Classroom setup

Set up your classroom connection.

Use Layers Teacher on a Windows PC and Layers Student in the students’ Chrome or Edge browsers. A room code connects the class.

Contact for current access

From teacher toolbar to student browser.

  1. Ask us for the current Windows Teacher build and the correct Student extension. Teacher for Mac is discontinued.
  2. Open Layers Teacher on Windows. Open Classroom and create a room.
  3. Have students open Layers Student in a supported webpage and enter the room code. Their connection appears in the classroom panel.
  4. Try sending a classroom link and show students how to ask for help.
  5. Configure Focus Mode, blocked sites or schedules for the lesson. Explain when browser restrictions will be applied.

Room codes connect a classroom; they are different from Guard Family device pairing codes. Classroom extension controls apply within participating browsers, not the whole student computer.

Microphone, translation and dictionary features may need permissions and a network connection. The toolbar cannot run on browser-internal pages such as chrome:// pages.

The old website used the same store URL for Student and Guard. Until the separate product listings are confirmed, we provide the correct extension access through the team.
