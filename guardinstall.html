Guard setup

Connect your family’s devices.

Use the web dashboard or Android Controller for parent controls. Install Guard Desktop on a child’s Windows PC or Guard Mobile on a child’s Android device.

Join the closed betaOpen dashboard

Follow the device’s setup flow.

  1. Get the right child app. Contact us for the current build and instructions for your Windows or Android device.
  2. Open your parent controls. Sign in to the web dashboard, or use the Android Controller. Use the same parent account when pairing devices.
  3. Pair with the child’s code. Choose Add device and use the current code shown by the child app. Codes expire; old screenshots may no longer work.
  4. Complete permissions. Windows needs parent/administrator setup for full website and firewall controls. Android needs the permissions shown by its setup flow.
  5. Check protection. Confirm that the expected device appears and review its protection and connection status.
  6. Set your rules. Choose daily limits, bedtime, app/site restrictions and schedules. Explain how the child can request time or access.

Android guidance

Do not confuse the free browser Guard extension with Guard Family’s child apps. The extension does not pair to this dashboard. Mac child apps are discontinued.

Before you finish

Check each device after a restart. If the dashboard shows missing permissions, reduced protection, or an old report, resolve that before relying on a rule. Use child-device diagnostics where available.

For unpairing, use the parent controls provided by the app. An online status or a saved rule alone does not prove that enforcement is active.
