Child apps for Windows & Android

Guard Desktop runs on the child’s Windows PC. Guard Mobile runs on the child’s Android phone or tablet. Both connect to your parent controls.

Independent browser tools

Layers Student supports learning. The free Guard extension provides browser-local protection; it does not pair with the family dashboard.
