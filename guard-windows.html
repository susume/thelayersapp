// Automatic protection

What the installer does for you

Windows Secure Mode automatically configures and verifies:

✓ Chrome Guest Mode disabled
✓ Chrome Incognito disabled
✓ New Chrome profiles disabled
✓ Extension Developer Mode disabled
✓ Layers Guard force-installed
✓ Rollback backup saved safely

Built to fail safely

The BAT file does not contain a second, simplified copy of the hardening logic. It downloads the already-audited PowerShell toolkit from a version-pinned public repository, verifies each downloaded file against its expected Git blob hash, and only then runs it. If verification fails, setup stops.

One important parent rule

The child's Windows account should be a Standard User, not an Administrator. Keep the administrator password with the parent. Windows Secure Mode strengthens Google Chrome; it does not control Firefox, Brave, Edge, native apps, other devices, or an Administrator user.
