Chrome on Windows

Make Chrome’s rules harder to sidestep.

Windows Secure Mode is an optional policy toolkit for the browser Guard extension. It is separate from Guard Desktop and requires parent administrator approval.

Understand the changes first.

The toolkit can disable Chrome Guest Mode, Incognito, adding profiles, and extension Developer Mode. With the correct published Guard extension ID, it can also configure force-installation.

These settings affect Chrome on the computer. They do not block other browsers or native apps. A child should use a Windows Standard User account. Without a verified Guard extension ID, force-install protection is incomplete.

  1. Contact us for the correct Guard extension and current policy setup instructions.
  2. Configure the extension’s local parent controls. Review the toolkit and keep its backup/restore instructions.
  3. Run parent setup with administrator permission only after confirming the correct extension ID. Check the result before giving the PC back to the child.
  4. Confirm the child’s Standard User account and test the expected Chrome rules.

Secure Mode helps reduce some browser bypass routes. It does not make a computer impossible to bypass and does not replace a device app or parent supervision. Older setup downloads may refer to an unconfirmed extension listing; ask us for current guidance.
