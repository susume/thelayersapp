Simple rules for the browser.

Blocked websites

Maintain a blocked-site list in the extension’s parent controls. Browser rules are applied within the configured browser.

Browsing schedule

Set allowed browsing hours and bedtime rules. Saved settings stay in the browser.

Content protection

Scan supported page text for concerning patterns and show a blur or alert. Scanning is best-effort and may miss content or produce false positives.

Know what it covers.

Browser Guard does not pair with the Guard Family dashboard. Its settings and PIN-gated parent panel are local to the browser.

It does not manage native apps, other browsers, routers, or the entire Windows account. Disabling or removing the extension can reduce protection. Browser permissions, private browsing settings, and the child’s Windows account type matter.

Need device-level controls?

For Windows and Android app rules, screen-time reporting, device locks and remote requests, use Guard Family with its child apps.

Optional Windows Secure Mode

Parents using Chrome on Windows can apply the separate Secure Mode toolkit. It configures Chrome policies that can reduce routes around browser protection, such as Guest Mode, Incognito, extra profiles and extension Developer Mode.

Administrator approval is required. Use a Standard User account for the child. Force-install protection needs the correct published Guard extension ID; the policy toolkit alone is not the Guard Desktop app.
